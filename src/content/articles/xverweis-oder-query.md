## Wann brauche ich das?

Werte sollen regelmäßig aus einer zweiten Tabelle übernommen werden.

## Schritte

1. Einmalige Zellhilfe von wiederholbarem Import unterscheiden.
2. Für eine überschaubare Excel-Formel XVERWEIS verwenden.
3. Für mehrere Dateien und wiederkehrende Transformationen Power Query wählen.

## Beispiel

Ein Segment nachschlagen → XVERWEIS; monatliche Exporte kombinieren → Power Query.

## Typischer Fehler

Große Formellandschaften aufbauen, obwohl dieselbe Aufbereitung jeden Monat wiederholt wird.
